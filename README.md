# huangguo_flutter

Flutter 短剧浏览、在线播放与下载管理应用。

## 手势解锁

iOS 显示名称为 `Flutter Demo`。在真实应用「设置 → 手势解锁」开启，
依次设置并二次确认 A、B；A 进入真实应用，B 进入交互演示页，两者必须不同。
修改两套手势或关闭开关前均需验证当前 A。设置中退出或切后台不会保存未完成的手势。

- 九宫格点位按从左到右、从上到下编号 1～9，至少连接 4 个不同的点；
  跨过未选择的中间点时自动补入，`1→4→7→8→9` 为大 L。
- 开关默认关闭。启用后，启动、锁屏或切后台再返回都重新验证，不记忆上一次
  进入真实页还是演示页；先输入 B，切后台回来仍可输入 A。
- 解锁层覆盖整个导航器，首次 A 验证前不创建真实页面。真实页锁定时暂停播放，
  iOS 使用原生遮罩覆盖最近任务截图。已有下载任务不会因锁定而删除或取消。
- 凭据以随机盐与 PBKDF2-HMAC-SHA256 派生值保存到系统安全存储，不保存明文手势，
  不加入业务数据迁移。读取失败保持入口锁定，可点击重试。
- 不提供绕过 A 的找回入口；请记住 A。手势入口不对已有业务文件实施加密。
  iOS Keychain 中的设置可能在卸载后保留，重新安装不保证重置。

## 首页状态与收藏

- 首页卡片左上角的星标可收藏或取消，点击星标不会进入详情；详情页也可操作。
  首页「我的收藏」展示本地收藏列表，点击卡片进入详情，取消最后一项后显示空态。
- 任意一集实际播放并产生正进度后，该剧标记「看过」，封面和标题淡化；
  这表示曾观看，不代表整部看完。在线和本地播放共用状态，未播放、零进度、
  暂停跳转或缓冲不会单独触发标记，下载与收藏图标不会随封面淡化。
- 绿色勾「有下载」表示至少一集已完成下载且存在本地资源，不表示整部下载完成。
  下载完成或在 App 中删除后自动更新，首页在 App 返回前台时重新检查资源。
- 已下载列表按集淡化并标记「看过」，专辑显示「看过 X / 已下载 Y 集」；
  本地播放器的选集列表同样展示观看状态，正在选择的剧集仍保留橙色高亮。
- `LibraryService` / `LibraryStorage` 将收藏元数据和按剧、按集的长期观看状态
  保存到应用文档目录的 `library.json`，使用串行写入和临时文件替换。
  启动时从现存播放历史回填正进度记录；之后不受最近 50 条历史上限、清空历史、
  取消收藏或删除下载影响。已被淘汰的旧历史无法回填，缺少剧 ID 的旧记录按剧名兼容。
- 读取损坏文件时不覆盖原文件，保存失败会记录错误，收藏操作也会提示未可靠保存。

## 播放器

在线播放和下载播放统一使用 `lib/widgets/app_video_player.dart`。
页面负责解析地址、创建与释放 `VideoPlayerController`，公共组件负责手势、
控制栏、全屏路由和屏幕方向；全屏切集通过共享状态更新，不重新进出全屏。

- 单击画面显示或隐藏控制栏；播放时 3 秒无操作自动隐藏，暂停时保持显示。
- 双击画面或点击全屏按钮进入横屏全屏；返回后恢复竖屏。
- 左右滑动预览目标时间，松手执行一次跳转；一屏最多调整 120 秒。
- 拖动进度条显示时间预览，结束后恢复拖动前的播放或暂停状态。
- 播放时长按临时使用 2 倍速，松开、取消或进入后台时恢复原倍速。
- 全屏快速上滑下一集、下滑上一集；内嵌模式保留页面纵向滚动。
- 支持倍速选择、缓冲进度、播放错误重试；离线播完停留，可点击播放重播。
- 手动选择的倍速在线/本地共用，切集、重试和重启 App 后恢复；长按临时固定 2×，松开恢复原倍速，不覆盖记忆值，手机端进入加速时轻震一次。
- 设置页的「离开播放页时暂停」默认开启，关闭可在 App 内切页继续播放；系统后台始终暂停，返回不自动恢复，全屏切换和菜单不触发离页暂停。
- 本地播放优先暂停在线播放，即使在线播放仍在加载也不会随后抢播；退出本地播放不会自动恢复在线声音。

历史进度只在进入对应剧集时恢复，手动或自动切集从头播放。
当前预览为时间预览，尚未实现视频缩略帧；保留在线 HLS、
本地视频文件和本地 HTTP 服务播放离线 HLS 的原有路径。

## 下载存储统计

- 「下载管理 → 已完成」底部固定显示设备总空间、设备已用和 App 占用，
  空列表和搜索时也保留；每套资源的「更多」菜单显示本套已下载文件总大小，
  不受搜索筛选集数影响。
- iOS、Android 统计应用本体与可读取的应用数据、缓存；macOS 沙盒构建也包含
  应用本体，其他环境只统计能读取的应用专属目录并标为「App 数据占用」。
  数值按文件逻辑大小估算，与系统设置的磁盘分配、共享及系统管理数据口径可能不同。
  设备容量对应应用所在存储卷，不包含其他外接存储卷。
- 源文件与转换后的 MP4 同时存在时均计入，同一路径不重复计算，不跟随符号链接。
  统计在后台 isolate 执行；进入已完成页、返回前台时刷新，下载变化合并后刷新，
  页面可见时每 20 秒更新，也可点击刷新按钮；读取失败显示「暂不可用」。
- MP4 转换前记录本集播放列表及其引用分片、密钥的总字节数和分片数；成功后记录
  MP4 大小、增减字节数、百分比及体积倍数。日志包含剧名和集名，批量转换在删除源文件前
  完成对比；复用已有 MP4 时明确记录跳过转换，统计失败不会中断转换。

## 验证

```sh
flutter analyze --no-pub --no-fatal-infos
flutter test --no-pub
flutter build ios --debug --no-codesign --no-pub
```

播放器测试覆盖控制栏显隐、进度拖动、取消手势、临时倍速恢复、
全屏源更新及窄屏布局。实际解码、网络片源与真机旋转仍需在设备上验收。

本机 Xcode 27 要求部署版本至少为 iOS 15。Runner 已设为 iOS 15，
`ios/Podfile` 同时将依赖的低版本部署目标提升至 iOS 15。
可使用以下命令编译或导出开发签名 IPA：

```sh
xcodebuild -workspace ios/Runner.xcworkspace -scheme Runner \
  -configuration Debug -sdk iphoneos -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO IPHONEOS_DEPLOYMENT_TARGET=15.0 build
flutter build ipa --release --export-method development --no-pub
```
